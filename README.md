# SunJobRadar

**把仓库交给你的 Agent，生成属于自己的本机求职工作台。**

Agent 引导你确认简历事实和求职意向，使用固定模板建立私人岗位库，再联网发现岗位、保存原始 JD 与匹配依据。你在浏览器里筛选、收藏、核对条件并准备申请材料。

初版 **v0.2.0 · 本机优先**。工作台运行只需 **Node.js 24.15+**，无需安装 npm 依赖，也没有内置的模型密钥要求。搜索与分析由你自己的 Agent 完成，相关工具、额度和隐私设置依该 Agent 而定。

## 用自己的 Agent 开始

下载或克隆：

```bash
git clone https://github.com/AuroraSunDev/SunJobRadar.git
```

让 Codex 或具备本机文件、命令执行和联网能力的 Agent 打开这个目录，告诉它：

> 阅读 AGENTS.md 和 skills/setup/SKILL.md，帮我在一个新的本机目录搭建求职工作台。先向我收集简历与求职意向，展示画像让我确认，再初始化、搜索真实岗位并验证入库。

它会依次协助你：

1. 检查环境，选择实例保存位置，读取你指定的简历或文字资料。
2. 补充目标岗位、地区、求职类型、毕业时间、硬性要求、排除条件和时间偏好。
3. 展示画像与事实来源；由你确认后创建独立工作台。
4. 检索真实岗位，保留链接、已读 JD 与逐项证据，导入后读回核对。
5. 打开本机看板；若你的 Agent 支持定时工具，再创建并核对检索任务。

**下载项目本身不会自动搜索或创建定时任务。** 没有联网工具时可先搭空工作台；本机定时任务需要电脑和相应 Agent 保持可用。保存“每两天 10 点”的偏好不代表调度已启用。

### Codex 插件形式

仓库也包含 plugin.json、安装引导和检索两个 Skill，以及 .agents/plugins/marketplace.json。支持本地插件市场的 Codex 客户端可添加本仓库为 marketplace，然后在插件目录安装 SunJobRadar、运行 setup。具体入口取决于客户端版本；直接打开仓库并读取 AGENTS.md 是不依赖市场界面的使用路径。

插件打包形式遵循 [OpenAI 官方插件文档](https://developers.openai.com/plugins/build/plugins)。本版验证重点是仓库引导、生成器、CLI 与浏览器闭环；不宣称已完成每个 Agent/客户端的原生安装认证。

## 不经过 Agent，先打开空工作台

在仓库根目录执行：

```bash
node scripts/create-workbench.mjs ../my-job-workbench
cd ../my-job-workbench
node cli.mjs serve
```

打开 [http://127.0.0.1:4173](http://127.0.0.1:4173)。访问码在新实例的 .sunjobradar/access-key，可由你的 Agent 协助读取；不要公开或提交访问码。页面可以先手动配置目标，详细简历事实和真实岗位由 Agent 后续补充。新实例没有预置的个人画像或真实岗位。

如端口被占用，可设置其他端口：macOS/Linux 使用 `PORT=4174 node cli.mjs serve`；PowerShell 使用 `$env:PORT=4174` 后运行启动命令。终端中 Ctrl+C 停止服务，关闭终端后服务也会停止。重新启动需要重新输入访问码。

## 已实现

- 自定义求职方向、地区、毕业月份、硬性要求和排除条件。
- 简历事实来源和个人贡献边界；五种要求状态，缺失资料保持待确认。
- 岗位关键词、方向、城市与证据状态筛选，收藏刷新后保留。
- 原始网址、JD 证据、检索来源和失败记录；URL 去重与同批次幂等重试。
- 修改画像后旧分析标记过期；导出带来源和过期提示的申请准备资料。
- 本机访问码、HttpOnly 会话、回环地址监听与同源写入保护。

本版没有内置搜索引擎/LLM、系统常驻服务、云部署或自动投递。下载申请准备文件不等于填表或提交。完整 JD、事实引用和结构验证也不能保证匹配推理正确，投递前应复核原站。

## 个人资料放在哪里

生成的实例与仓库开发目录分开。个人数据库、访问码和 Agent 私人输入保存在实例 .sunjobradar/，该目录被 Git 忽略，默认目录权限 0700、文件 0600。不要将自己的实例、简历或运行日志上传到公开仓库。公开示例全部虚构；开发者的个人云工作台不包含在这个项目中。

本项目没有内置遥测或外部上传。使用 Agent 读取简历时，资料仍可能由你选择的模型服务处理；以该产品的数据设置为准。本机访问保护不等同于系统账户隔离，也不适合改为公网服务。
