# SunJobRadar

面向中国应届毕业生的个人求职工作台。产品目标是让用户设置一次求职偏好，持续发现目标企业官网中值得关注的新岗位，并统一查看、筛选和收藏。

## 当前版本

目前完成的是 **Web 前端界面演示**，用于确认页面外观、信息结构和基本交互。包含以下页面：

| 页面 | 地址 |
| --- | --- |
| 新发现 | `/` |
| 全部岗位 | `/jobs` |
| 岗位详情 | `/jobs/[id]` |
| 已收藏 | `/saved` |
| 监控设置 | `/monitoring` |
| 个人设置 | `/settings` |
| 登录欢迎 | `/login` |
| 首次配置 | `/onboarding` |

可以演示岗位搜索与筛选、收藏与隐藏、三步首次配置和设置表单。岗位、企业、匹配理由、检查时间及数据源状态均为**示意内容**；演示状态刷新页面后会重置。

尚未接入真实账户、企业招聘官网、定时检索、岗位去重、AI 匹配或简历上传。页面中的“访问官网”不指向真实岗位。

## 本地运行

需要 Node.js 20.9 或更新版本。

```bash
npm ci
npm run dev
```

打开 [http://localhost:3000](http://localhost:3000)。

可用 `npm run lint` 检查代码，或用 `npm run build` 验证生产构建。
