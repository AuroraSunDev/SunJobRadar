# SunJobRadar 本机 Agent 工作台初版

用户已选定本机优先，并明确授权完成后推送 AuroraSunDev/SunJobRadar 作初版发布。原个人云工作台继续私有。

## 使用闭环

安装仓库或插件 → Agent 检查 Node.js 24.15+ 与联网工具 → 读取用户选定的简历 → 逐项确认求职画像与事实依据 → 从固定模板生成独立目录 → CLI 初始化 → 启动仅监听回环地址的工作台 → Agent 搜索真实岗位并按契约导入 → 读回核对。无需模型 API 密钥；检索与分析使用用户自己的 Agent 能力。缺少联网或调度工具时明确报告，仍可启动空工作台。

## 范围

- 新增零第三方运行依赖的 Node.js/SQLite 本机模板，不修改原 Next.js 旧版界面或私人数据库。
- 画像包括自定义目标岗位、地区、求职类型、毕业月份、硬性要求、排除条件、事实与来源、期望检索时间及时区。
- 岗位包括网址、真实读取时间、来源状态、JD 正文/片段、逐项匹配状态和事实引用；五态匹配，不提供虚构匹配分。
- 看板提供岗位、收藏、检索记录、画像四个入口，文本/方向/城市筛选，详情与准备资料导出。画像更新后旧分析过期。
- CLI 提供 init/read/profile/import/schedule/serve。导入事务性、网址去重、相同运行 ID 同负载幂等、不同负载冲突；旧记录和失败不覆盖较新证据。
- 浏览器 API 需本机访问码建立 HttpOnly 会话，严格回环 Host、同源写入、请求大小限制。Agent 直接使用 CLI，无需浏览器凭据。
- 仅记录已被实际创建并核对的外部调度；默认未启用。优先 Codex，其他具备本机文件、运行命令、联网能力的 Agent 可按同一契约操作；不承诺未经测试的原生集成。
- 不实现云部署、自动投递、内置 LLM 或搜索付费服务、系统常驻调度。

## 分发与隐私

仓库增加插件清单、setup/collect 两个 Skill、Agent 通用入口、生成器、模板、虚构样例、MIT 许可和初版说明。生成器只复制模板白名单，拒绝覆盖已有目录，不复制 .git、个人简历、数据库、云配置或密钥。个人配置位于生成目录中被忽略的 .sunjobradar/。发布中不得出现个人云站点标识或真实经历资料。

## 验收

在全新临时目录从生成器启动，不安装 npm 依赖；初始化虚构画像、真实 Agent 搜索试跑、导入和读回、重复导入、失败保留、过期提示、浏览器授权/拒绝跨源、收藏刷新持久化、桌面/手机布局。原 13 项测试继续通过。只在检查提交范围、远端最新提交及隐私扫描后推送；初版版本为 v0.2.0，保留 v0.1 旧版运行方式。
